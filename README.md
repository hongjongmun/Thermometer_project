# 🌡️ 비접촉식 온도 측정 디바이스 (ThermoCheck)

> **사용자의 스위치 입력을 기반으로 비접촉 온도 측정 센서를 제어하고, OLED 화면에 결과를 시각화하는 임베디드 시스템 프로젝트입니다.**  
> 버튼 입력에 따라 단기/장기 이벤트를 감지하며, 측정된 온도는 실시간으로 분석되고 상태(저체온/정상/고온)에 따라 다른 UI가 출력됩니다.

---

## 🛠️ 주요 기능 요약

| 기능 구분 | 설명 |
|-----------|------|
| 📍 스위치 입력 | 짧게 누르거나 길게 누른 입력을 감지하여 다른 이벤트로 분기 |
| 🌡️ 온도 측정 | IR 기반 센서를 이용해 1.5초간 여러 번 온도 측정 후 최대값 도출 |
| 🧠 온도 해석 | 최대 온도값을 기준으로 저체온, 정상, 고온 여부 판단 |
| 🖥️ OLED 출력 | 측정 결과를 그래픽으로 직관적으로 시각화 |
| 🔀 버튼 분기 | 좌/우 버튼에 따라 다른 동작 실행 가능 (후속 기능 확장에 유리한 구조) |

---
